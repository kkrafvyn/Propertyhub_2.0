# Play Store screenshot pass (manual)

After Wave 2 consumer UI work, capture fresh store assets from staging or production-like build.

## Checklist

1. **Phone screenshots (1080×1920 or 1440×2560)** — Property search, listing detail, consumer hub (`/app`), property journey timeline, checkout degraded/sandbox banner if applicable.
2. **Feature graphic (1024×500)** — Hero search + BaytMiftah wordmark; match current marketing palette.
3. **Short description** — Align with `ConsumerJourneyShowcase` disclaimer: marketing previews may differ from live flows.
4. Upload to Play Console → Store presence → Main store listing.

Track completion in release notes; no automated gate in CI.
