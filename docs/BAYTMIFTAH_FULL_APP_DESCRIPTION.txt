1. WHAT BAYTMIFTAH IS
================================================================================

BaytMiftah is an end-to-end real estate platform. It connects people who want
to rent, buy, or book short stays with property professionals (agents, landlords,
operators, and enterprise portfolios). One codebase powers multiple experiences:

  • Consumer — marketplace and personal portal (web + native mobile app)
  • Business Workspace — CRM, operations, finance, and compliance (web,
    Windows desktop app, and native workspace mobile app)
  • Platform Admin — internal staff console for users, orgs, trust, fraud,
    revenue, and platform configuration (web; not a separate admin mobile app)

The platform is built on React, TypeScript, Vite, and Supabase (PostgreSQL,
Auth, Realtime, Storage, Edge Functions). Native Android and iOS shells use
Capacitor. The Windows desktop product packages the workspace experience in
Electron with hash routing for offline-capable field use.

2. CONSUMER PRODUCT (com.baymiftah.app)
================================================================================

2.1 Marketing and discovery (no login required)
--------------------------------------------------------------------------------
  • Home / marketplace index — entry to search and featured inventory
  • Marketing site — product story, tours, AI positioning, proof points
  • Property search — filters by location, price, property type, listing type
    (rental, sale, short stay), maps, and list views
  • Property detail — photos, amenities, pricing, enquiry and booking actions
  • Compare — side-by-side comparison of saved listings
  • Public property explorer — browse units and properties without an account
  • Public event / transaction explorer — transparency views on ledger events
  • Shared shortlist — shareable curated property lists
  • Referral program page

2.2 Public workflows (token or link based)
--------------------------------------------------------------------------------
  • Public lease application — apply to a specific estate/listing via link
  • Public e-sign — sign documents from email/SMS links
  • Owner / board portals — tokenized access for owners and HOA-style boards
  • Contractor access — limited portal for external contractors via token

2.3 Authentication and account
--------------------------------------------------------------------------------
  • Sign up, login, forgot password, email verification
  • OAuth providers where configured (alongside email/password)
  • Security settings — password, sessions, MFA where enabled
  • Profile and preferences under My BaytMiftah (/app)

2.4 My BaytMiftah — consumer portal sections
--------------------------------------------------------------------------------
After sign-in, users manage their property life in one hub:

  Overview (Home)
    Dashboard of saved items, viewings, recommendations, activity, and
    pending e-signatures.

  Saved properties
    Bookmark listings from search; build a shortlist.

  Messages
    Conversations with agents, hosts, and property teams (realtime where
    connected).

  Offers and applications
    Rental, lease, and purchase deal cases; status of each workflow.

  Property journey
    Per-deal timeline: stage, next actions, documents (/app/journey/...).

  Viewings
    Requested and confirmed property visits.

  Saved search alerts
    Notifications when new listings match saved criteria.

  Payments and wallet
    Payment confirmation, receipts, and history (provider-confirmed records).

  Transactions
    Deposits, installments, and purchase-related payment activity.

  Leases
    Active tenancies, rent context, and lease-linked tools.

  Trips and reservations
    Short-stay bookings — upcoming trips and full reservation history.

  Documents
    IDs, leases, agreements, receipts, and shared files.

  Maintenance
    Submit and track maintenance requests; link to vendor marketplace.

  My Home (resident)
    Smart-building style tools when on an active lease (access, utilities,
    announcements — as enabled for the property).

  Mortgage marketplace
    Compare lenders, estimate payments, request introductions (buyers).

  Insurance marketplace
    Home and contents quotes from partner insurers.

  Vendor marketplace
    Verified maintenance and property service providers.

  Notifications
    Central feed for bookings, payments, messages, and system updates.

  Identity verification (KYC)
    Government ID, liveness, and AML compliance when required for offers,
    bookings, or high-trust actions.

  Profile and settings
    Account, legal acceptances, notification preferences, workspace access.

  Contextual messages portal
    Deep-linked messaging contexts outside the main dashboard layout.

  Workspace access
    Switch or request access to business workspaces tied to the user account.

2.5 Checkout and commerce
--------------------------------------------------------------------------------
  • In-app checkout — short-stay and other payable flows (verified email

    and card rails where enabled).

2.6 Legal, trust, and support content
--------------------------------------------------------------------------------
  • Privacy policy, terms of service, legal hub with document slugs
  • Complaint form, public status page, sitemap
  • Static pages: help, cancellation, host resources, workspace roles, about,
    careers, contact

2.7 Global consumer UX
--------------------------------------------------------------------------------
  • Mobile bottom navigation on consumer routes
  • Cookie consent and policy update banners
  • Location onboarding where relevant
  • New user tutorial and getting-started checklist
  • BaytMiftah AI panel (contextual assistant on supported surfaces)
  • Voice/video calling UI — WebRTC calls with agents/teams when enabled

3. BUSINESS WORKSPACE (com.baymiftah.workspace + web/desktop)
================================================================================

3.1 Getting into a workspace
--------------------------------------------------------------------------------
  • Workspace entry — pick organization; role-aware landing
  • Accept invite — join org from invitation link
  • Enrollment status — company onboarding pipeline
  • Desktop gateway — web path for desktop app users
  • Company setup wizard — first-time org configuration for owners
  • Multi-organization switching — users can belong to many orgs

Access is organization-scoped with role-based permissions (owner, admin, agent,
finance, maintenance, custom roles, and platform admin viewer modes). Members
may be scoped to subsets of properties. Navigation is customizable per org
(terminology presets, hidden modules, default home page).

3.2 Core workspace modules (primary navigation)

    Executive and role dashboards; KPIs and work queues.

  Listings

  Tasks
    Operational task lists tied to deals and properties.

    Viewings, inspections, and operational scheduling.

  Payments

  Team
    Members, roles, invites, permissions.

    Lease lifecycle, terms, renewals, commercial escalations.

  Maintenance
    Work orders, vendors, resident requests.

    Day-to-day property and estate management operations.

================================================================================
6. BACKEND AND AUTOMATION (SUMMARY)
================================================================================

Supabase Edge Functions handle webhooks, notifications, SMS, email (Resend),
organization invites, enrollment notifications, automation dispatch, payment
hooks, and other server-side workflows. PostgreSQL holds multi-tenant org data,
listings, deal cases, leases, ledger entries, communications, and audit trails.
Realtime channels power live messaging and presence where enabled.
